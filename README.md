# 🛠️ community-builds

Shared build space for **[ship-together](https://github.com/ship-together)** members to hang out, make dev friends, request invites, and build projects together.

## 🎟️ Want to Join `ship-together`?
Open a new issue using the **Invitation** template and include:
* **GitHub Username** (so we can send your organization invite)
* **Discord Username** (so we can connect on Discord)
* **What you like to build & how you want to jump in**

👉 [Request an Invite to ship-together](https://github.com/ship-together/community-builds/issues/new?labels=invite-request&template=invitation.yml&title=Please+invite+me+to+the+ship-together+GitHub+Organization)

## 💡 What Happens Here
* **Hang Out & Connect:** Meet fellow builders, trade ideas, and chat on Discord.
* **Co-Build & Pair Up:** Team up on web, mobile, Web3, AI, scripts, or weekend prototypes.
* **Learn & Ship:** Share progress, review pull requests, and turn ideas into real projects.
